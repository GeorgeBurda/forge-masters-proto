# Forge Masters — slot prototype

Live: https://georgeburda.github.io/forge-masters-proto/

4 reels x 3 rows, 81 ways, bet 10. Tap anywhere to spin; tap during an animation to skip to the result.

URL params: `?seed=N` (seeded RNG), `?debug=1` (pre-decided outcome panel), `?mute=1`.

Cheat (prototype only, when idle): tap a blacksmith to arm Master Strike on his reel for the next spin (tap again to disarm, several smiths = several reels); tap the furnace to arm the Forge bonus for the next spin.

Heat glow is purely cosmetic (spin tempo), it never affects outcomes. Whole spin result (incl. the full bonus) is decided at the tap.

Single self-contained `index.html` + `assets/`. Source, math sims and tests live outside this deploy repo.
